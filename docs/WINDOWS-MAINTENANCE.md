# Windows 维护版

悬浮球显示当前正在生成的线程数（包含子代理），以及该悬浮球当前所选 token 速度除以线程数的平均值；空闲或没有正在生成的线程时平均值显示 `—`。这些值沿用原有日志解析和估算结果，并跟随悬浮球的数据源筛选及输出/总量指标。

此维护版默认不自动检查官方更新；已有设置仍可显式控制该开关。每次安装覆盖前应保留用户设置，特别是 WSL 数据源、上报和自动更新偏好。GitHub 代码维护仓库使用 `origin`，原项目使用 `upstream`；在审查和测试通过后，将提交推送到 `origin/main`。推送源码不会自动替换用户电脑上的程序，也不会自动运行不受审查的工作区变更。
